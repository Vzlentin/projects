# projects

This repository will hold the project store of the harness stack: projects, work items, parleys and contracts.
It will publish two npm packages with one version. `@vzlentin/projects` will hold the host entry, the protocol, the tools and the `projects` command. `@vzlentin/pi-projects` will hold the Pi package.
It is part of the harness stack, with [harness](https://github.com/Vzlentin/harness) and [workflows](https://github.com/Vzlentin/workflows).
The code is not here yet. It moves from harness in a later change.
